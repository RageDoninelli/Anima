# Anima — Chronicles of Gaia · Edición 1.0 (campaña adaptada)

Aplicación web progresiva estática e independiente de aficionados, sin afiliación con los titulares de *Anima: Beyond Fantasy*. No se redistribuyen los manuales ni su contenido protegido.

## Contenido
- Base de la alfa 0.6: ficha, generación de ocho características, tiradas abiertas D100, prólogo, inventario, objetivos, PNJ, atlas, mesa de juego manual, oráculo, guardados, instantáneas y copias JSON.
- Nuevo: **El juramento de la niebla**, campaña original de ocho capítulos con decisiones, pruebas, combates simplificados, experiencia de campaña, descanso, finales y exportación/importación de la campaña.
- Nueva sección de campaña accesible desplazándose bajo «Mesa de juego».

## Límites de fidelidad
El motor de combate de la campaña y su experiencia/niveles son **adaptaciones originales simplificadas** para juego en solitario. No equivalen a las reglas oficiales de combate, categorías, puntos de desarrollo, magia, Ki ni poderes psíquicos de Anima. La ficha y el prólogo preexistentes también implementan solo una parte de las reglas. La narración está preescrita con decisiones y oráculo: **no es una IA conversacional**. La campaña tiene ocho episodios lineales con ramificaciones y varios finales, no un mundo abierto infinito.

## Publicación
Sube **el contenido** del ZIP a la raíz de un repositorio de GitHub Pages (no el ZIP mismo). Configura Settings > Pages > Deploy from branch > main / (root). Abre la URL por HTTPS e instala la PWA desde el navegador compatible. El guardado se hace en el almacenamiento local del origen; no se sincroniza entre dispositivos.

## Protección de personajes
1. Antes de reemplazar archivos, entra en tu versión actual y pulsa **Descargar respaldo completo** en «Santuario de héroes».
2. Guarda el JSON fuera del navegador y conserva el ZIP anterior.
3. Sube los nuevos archivos **sin borrar datos del sitio ni cambiar la dirección GitHub Pages**.
4. Comprueba que tu personaje se mantenga. Si no, usa **Restaurar respaldo completo** y selecciona el JSON.
5. La campaña nueva se añade al guardado existente; no cambia las ocho características de tu personaje. Puedes exportar su progreso de campaña por separado.

No pulses «Nueva partida» para actualizar. Si cambias de dominio o repositorio, el almacenamiento local anterior no se traslada automáticamente: importa el JSON.

## Comprobaciones recomendadas
Prueba en Android: crear héroe, generar estadísticas, guardar, refrescar, iniciar campaña, superar una prueba, resolver combate, exportar/importar campaña, exportar respaldo completo, restaurar, comprobar modo sin conexión después de una primera carga online.
